# 车机行车记录仪 · 手机远程查看方案（手机开热点版）

适用于 **24 款雪佛兰科鲁泽**（23/24 款车机均为 Android 10 底层，方法相同）。
**手机开热点 → 车机连接热点 → 车机运行「录像服务器」→ 手机用「录像查看器」App（或浏览器）在线浏览、播放、下载行车记录仪录像。**

> 核心原理：车机自带的记录仪视频存放在车机内置存储里。车机连接手机热点后，与手机处于同一局域网；车机上运行的「录像服务器」把录像目录通过 HTTP 共享出来，手机访问车机 IP 即可查看。全程局域网直连，**不消耗手机流量**（热点仅供车机-手机之间传输录像）。

## 二、首次使用步骤

### 第 1 步：手机开热点
手机开启「个人热点 / 便携式 WLAN 热点」（建议 2.4GHz 频段，兼容性最好），记下热点名称和密码。

### 第 2 步：车机连接手机热点
在车机 Wi-Fi 设置中连接手机热点。连接成功后，车机与手机在同一局域网。

### 第 3 步：车机端安装并启动录像服务器（一次性）
1. **开启车机 adb**：车机"拨号"界面输入 `*#111#*` 拨打 → 点击 **WIFI ADB**（车机会重启一次）→ 再输一次 `*#111#*` 确认开启。
2. **电脑连接车机**：电脑和车机连同一 Wi-Fi，`adb connect <车机IP>:<端口>`（IP/端口以车机 WIFI ADB 界面显示为准）；或用手机"甲壳虫 ADB" App 无线连接。
3. **安装车机端**：`adb install -r dist\CarCamServer.apk`（或在车机上直接打开 APK 安装）。
4. 打开「车机录像服务器」→ 授予**存储权限** → 点【启动录像服务器】→ 点【扫描录像目录】选择记录仪录像目录（一般自动识别）。
5. 确认 App 首页显示**热点分配的 IP**（如 `192.168.43.x`）和访问地址（如 `http://192.168.43.2:8080`）。

> 小技巧：想确认录像存在哪个目录，可先 `adb shell ls /storage/emulated/0/`；App 的"扫描录像目录"会把视频最多的目录排在前面。

### 第 4 步：手机查看
1. 保持手机热点开启（不要退出）。
2. 打开「车机录像查看器」→ 点【自动扫描（本机热点网段 + 常见网段）】→ 点出现的服务器条目（约 15 秒内完成）。
3. 进入目录 → 点视频**在线播放**（支持拖动进度）→ 点【下载】保存到手机「下载」目录。

**不用装 App 也能看**：手机浏览器直接打开车机端显示的地址（如 `http://192.168.43.2:8080`）即可浏览播放。

## 三、常见问题

| 现象 | 原因 / 解决 |
|---|---|
| 自动扫描找不到车机 | ① 手机热点要**保持开启**（部分手机热点开启后一段时间无客户端会休眠，重新开一下）；② 车机端服务没启动或没显示 IP；③ 车机未连上手机热点；④ 车机 IP 不在常见网段（192.168.43/31/137/0/1、172.20.10），用车机端 App 显示的 IP 手动输入 |
| 手机热点需要流量吗 | 不需要。车机连上后只与手机局域网通信，不上网，不消耗流量 |
| 车机 IP 每次都变 | 正常，热点 DHCP 分配。直接用查看器「自动扫描」，或上车机 App 首页看一眼 IP |
| 播放失败 / 无法拖动 | 录像格式车机播放器不兼容时请点【下载】到手机用播放器打开；拖动进度依赖服务器 Range 支持（本 App 已实现） |
| 车机端服务被系统杀掉 | 在车机"设置-应用-自启动管理"里允许「车机录像服务器」后台运行/自启动 |
| 找不到录像目录 | 车机上先正常录制一段；在 App 里【扫描录像目录】选择视频最多的目录；仍找不到可 `adb shell` 确认实际存储路径 |
| 车机非安卓/无法装 APK | 本方案仅适用于可安装第三方 APK 的车机；科鲁泽 23/24 款车机（Android 10）可安装（参考懂车帝/B站教程） |

### 扫描不到录像？按顺序排查

**已通过反编译车机记录仪 App（com.jsbd.cameraservice）确认录像存储位置：**
- **行车循环录像（主要）：`/dvr/Video/`**（车机根目录下的厂商路径，文件为 `yyyy-MM-dd-HH-mm-ss.mp4`）
- **手动/锁定录像与抓拍：`/storage/emulated/0/DCIM/DVR/`**（`Record/` 子目录存锁定录像，`Picture/` 子目录存抓拍）

v1.3 已将这两个路径加入自动扫描根，并支持从根目录 `/` 手动浏览查找。

> **⚠ 重要发现（来自 App 反编译）**：记录仪服务启动时若检测到系统设置 `dvr_app_launch_state == 0`，会**自动清空 `/dvr/Video/` 目录**。因此该目录为空可能是：① 记录仪从未开启/录像失败；② 车机重启后触发了上述清空逻辑。请先在车机原厂记录仪界面确认是否有录像列表，再用下方命令全盘验证。

1. **确认车机上确实有录像**：在原厂记录仪界面查看录像列表；若界面也没有，说明记录仪未开启录像（去设置开启循环录像，开一段路后再看）。
2. **确认权限真的授予了**：车机设置 → 应用 → 车机录像服务器 → 权限 → 存储"允许"。可用 adb 验证：
   ```
   adb shell dumpsys package com.carcam.server | grep -A4 "runtime permissions"
   ```
   应看到 `READ_EXTERNAL_STORAGE: granted=true`。
3. **用 adb 全盘确认录像文件存在哪**（Windows 下先 `adb connect 车机IP:端口`）：
   ```
   adb shell "find / -maxdepth 6 -name '*.mp4' 2>/dev/null | head -30"
   adb shell "ls -la /dvr/ /dvr/Video/ /storage/emulated/0/DCIM/DVR/ 2>/dev/null"
   adb shell "logcat -d | grep -iE 'MediaRecorder|mediaserver|dvr|record' | tail -40"
   ```
   把输出发我：有 `.mp4` 列表即可定位真实目录；没有 `.mp4` 说明还没录过像（先开记录仪录一段）；`Permission denied` 说明厂商限制了第三方读取。
4. **用 App 内【浏览存储找录像】手动定位**：新版本从根目录 `/` 开始翻，直接找 `dvr` 文件夹（点开应看到 `Video/`），看到视频文件后点击即自动选中其所在目录为录像目录。
5. **若 /dvr 提示"无权限读取"**：第三方 App 被厂商限制，可行的出路是把输出发我，一起评估（如 adb 拷贝导出、或配合原厂 U 盘导出）。

## 四、从源码重新构建

- **Linux/macOS**：`bash tools/build_apk.sh`（需 JDK 8+、Android SDK build-tools 30.0.3）
- **Windows**：先装 Android SDK，再运行 `build_all.bat`（自动定位 build-tools 与 android.jar）

修改端口：改 `server/.../CamServerService.java` 中 `DEFAULT_PORT = 8080`。

---

## 五、安全说明

- 服务仅监听局域网（手机热点），**无鉴权**，连上该热点的设备都能访问录像，请勿在陌生公共网络使用。
- 记录仪视频含车辆周边影像，属个人隐私数据，请妥善保管手机端下载内容。
